# 2. Запись и чтение

```java
void example() {
    ByteBuffer buffer = ByteBuffer.allocate(16);

    buffer.put((byte) 7);              // относительная запись: пишет в position, сдвигает его
    buffer.putInt(250);                // 4 байта сразу: position += 4
    buffer.put(new byte[]{1, 2, 3});   // массивом: position += 3

    buffer.put(0, (byte) 9);           // абсолютная запись по индексу: position НЕ меняется

    buffer.flip();                     // -> режим чтения
    byte first = buffer.get();         // относительное чтение
    int number = buffer.getInt();      // 4 байта
    byte third = buffer.get(5);        // абсолютное чтение: position НЕ меняется
}
```

| Метод | Что делает | position |
|---|---|---|
| `put(b)` / `get()` | один байт | +1 |
| `put(byte[])` / `get(byte[])` | массив целиком | + длина |
| `putInt` / `getInt`, `putLong`, `putDouble`, ... | значение «одним куском» (4/8 байт) | + размер типа |
| `put(i, b)` / `get(i)` | по абсолютному индексу | не меняется |
| `remaining()` | `limit - position` — сколько осталось | — |
| `hasRemaining()` | `position < limit` | — |

Выход за границы — это исключения, а не тихая порча памяти:

| Ситуация | Исключение |
|---|---|
| `put`, когда `remaining()` меньше размера значения | `BufferOverflowException` |
| `get`, когда `remaining()` меньше размера значения | `BufferUnderflowException` |
| абсолютный индекс ≥ `limit` | `IndexOutOfBoundsException` |
| запись в буфер только для чтения | `ReadOnlyBufferException` |
