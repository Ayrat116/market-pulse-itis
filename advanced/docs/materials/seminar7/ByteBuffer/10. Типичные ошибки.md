# 10. Типичные ошибки

| Ошибка | Что происходит | Как правильно |
|---|---|---|
| Забыт `flip()` после записи | читаются нули/мусор; `channel.write` отправляет 0 байт | `flip()` между записью и чтением |
| `clear()` вместо `compact()` при частичном чтении | непрочитанные байты затираются новыми | `compact()`, если прочитано не всё |
| Предположение «`read` прочитал всё сообщение» | сообщение приходит кусками; разбор падает на обрезанных данных | накапливать данные и разбирать, когда набралось достаточно |
| `read` вернул `0` приняли за EOF | преждевременное закрытие соединения | EOF — это только `-1`; `0` — «пока нет данных» |
| Разный `ByteOrder` у автора и читателя | числа читаются «перевёрнутыми» без ошибки | явно задавать `order(...)` по формату протокола |
| `array()` на direct- или mapped-буфере | `UnsupportedOperationException` | проверять `hasArray()` или читать через `get(byte[])` |
| `allocateDirect` на каждый запрос | дорогое выделение, память освобождается только после GC | один раз создать и переиспользовать (`clear()`) |
| Один буфер из нескольких потоков | `position`/`limit` портятся — буфер не потокобезопасен | буфер на поток или внешняя синхронизация |
