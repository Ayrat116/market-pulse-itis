# 3. java.nio: каналы и буферы

Канал (`Channel`) — **двунаправленное** соединение с источником данных; данные в него и из него
передаются только через [`ByteBuffer`](../ByteBuffer/1.%20Анатомия.md).

| Канал | Источник |
|---|---|
| `FileChannel` | файл (чтение, запись, `map`, блокировки) |
| `SocketChannel` | TCP-соединение (клиентская сторона) |
| `ServerSocketChannel` | приём входящих TCP-соединений |
| `DatagramChannel` | UDP |

```java
void example() throws IOException {
    try (FileChannel in = FileChannel.open(source, StandardOpenOption.READ);
         FileChannel out = FileChannel.open(target, StandardOpenOption.CREATE, StandardOpenOption.WRITE)) {

        ByteBuffer buffer = ByteBuffer.allocate(8192);
        while (in.read(buffer) != -1) {     // канал -> буфер
            buffer.flip();
            out.write(buffer);              // буфер -> канал
            buffer.compact();
        }
    }
}
```

| Операция | Потоки (`java.io`) | Каналы (`java.nio`) |
|---|---|---|
| Направление | отдельно `Input*` и `Output*` | один канал в обе стороны |
| Куда читаем | в `byte[]` | в `ByteBuffer` (с `position`/`limit`) |
| Копирование файла без прогона данных через Java | нельзя | `transferTo` / `transferFrom` |

```java
void copy() throws IOException {
    try (FileChannel in = FileChannel.open(source, StandardOpenOption.READ);
         FileChannel out = FileChannel.open(target, StandardOpenOption.CREATE, StandardOpenOption.WRITE)) {
        in.transferTo(0, in.size(), out);   // ядро ОС копирует само, данные не попадают в кучу JVM
    }
}
```
